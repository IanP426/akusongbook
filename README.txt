AKU RADIO — GitHub API 관리자 버전

1. 저장소의 루트에 index.html, songs.json, assets 폴더를 업로드하세요.
2. GitHub Settings > Pages 에서 main/(root)를 선택하세요.
3. GitHub Settings > Developer settings > Personal access tokens > Fine-grained tokens에서 토큰 생성. Repository access: 해당 저장소만, Repository permissions: Contents Read and write.
4. 사이트에서 관리자·곡 관리 클릭 후 owner/repo, branch(main), token 입력.
5. 처음에는 GitHub에서 최신 목록 불러오기 클릭. 곡 추가·수정·삭제 후 GitHub에 저장 클릭.
6. 토큰은 HTML에 포함되지 않고 브라우저 저장소에도 저장되지 않습니다. 공유 PC에서 토큰을 입력하지 마세요.
7. 공개된 관리 UI 자체는 누구나 볼 수 있으나 GitHub 쓰기 권한이 없으면 저장 불가합니다.
8. 변경은 GitHub Pages 배포 및 캐시 갱신 후 모든 방문자에게 보입니다.
9. 이 버전은 SOOP 영상 종료 후 자동 다음 곡 기능을 제공하지 않습니다.
